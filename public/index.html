⚡ 开放自动化 REST API 文档

适合 Python、Node.js、Selenium、Playwright 等自动化注册脚本对接，秒取最新验证码！

1. 极速提取验证码 (支持通过邮箱或平台名查询)

# GET /api/external/code?email=xxx@yourdomain.com
# 或根据平台名称模糊查找：GET /api/external/code?platform=OpenAI
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://YOUR_DOMAIN/api/external/code?email=test_user@yourdomain.com"

# 响应示例：
{
  "success": true,
  "code": "849201",
  "link": "https://auth.openai.com/verify?token=xxx",
  "subject": "Your OpenAI verification code",
  "received_at": "2026-11-11 14:30:00"
}

2. 自动分配临时邮箱并记录到平台台账

# POST /api/external/register
curl -X POST "https://YOUR_DOMAIN/api/external/register" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "platform_name": "Claude",
    "password": "Password123!",
    "category": "AI工具",
    "remark": "美国住宅IP自动注册"
  }'

# 响应示例：
{
  "success": true,
  "data": {
    "id": 12,
    "email": "claude_8f2a1b@yourdomain.com",
    "platform_name": "Claude"
  }
}
