⚡ 自动化脚本 RESTful API 文档

专为 Python、Node.js、Selenium、Playwright 自动化脚本打造，提供直连提取验证码接口！

📄 查看原始 Markdown 📐 查看 JSON 契约
GET /api/external/code

极速提取最新验证码，支持传入邮箱地址 ?email=xxx 或平台名称 ?platform=OpenAI 自动模糊匹配。

cURL 示例 
curl -H "X-API-Key: cf_mailhub_api_key_8888" \
  "https://vault.439949.xyz/api/external/code?platform=OpenAI"
响应 JSON 格式 
{
  "success": true,
  "code": "849201",
  "link": "https://auth.openai.com/verify?token=xxx",
  "subject": "Your OpenAI verification code",
  "received_at": "2026-11-12 09:30:00"
}
POST /api/external/register

自动分配自建域名临时邮箱并原子化记录到平台资产台账，避免多处手动复制。

cURL 示例 
curl -X POST "https://vault.439949.xyz/api/external/register" \
  -H "X-API-Key: cf_mailhub_api_key_8888" \
  -H "Content-Type: application/json" \
  -d '{
    "platform_name": "Claude",
    "password": "Password123!",
    "category": "AI工具",
    "remark": "美国住宅IP自动注册"
  }'
响应 JSON 格式 
{
  "success": true,
  "data": {
    "id": 12,
    "email": "claude_8f2a1b@439949.xyz",
    "platform_name": "Claude"
  }
}
