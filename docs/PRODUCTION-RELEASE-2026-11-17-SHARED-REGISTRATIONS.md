## 已上线的功能

新增「邮箱资产」页面和共享登记抽屉，按实际收件地址与来源查看平台、登记、连接状态和影响范围，可继续登记新平台。每条平台注册独立维护密码、2FA、工作区、账号标识、登录方式、收件别名、验证规则和生命周期日期。

平台取码按发件人/关键词规则匹配，缺少规则时显示配置入口；明确选择「查整个邮箱」后才做邮箱范围查询。只有平台匹配结果写入该登记的历史验证码，CF 来信不再向所有共享登记广播同一个码。导入默认合并并保留省略的凭据，预览显示动作、目标 ID 和变更字段名；支持显式替换与 TXT/CSV 的 21 列往返。

有效收件地址统一接入权限、邮件保留、连接解绑和备份。实际消费账号快照时重新授权，并对写入和历史码更新做并发检查。4 个邮箱身份 API、OpenAPI、Postman、AI 指南和 TypeScript/Python SDK 文档已同步。详细操作见 [平台账号](PLATFORM-ACCOUNTS.md)、[账号交换](ACCOUNT-TRANSFER.md) 和 [SDK](SDK.md)。
