# 一邮箱多平台注册：实现与验证

日期：2026-11-17。下文记录本地实现验收；随后已按用户授权推送并发布生产，版本、备份及回读证据见 [生产发布记录](PRODUCTION-RELEASE-2026-11-17-SHARED-REGISTRATIONS.md)。

## 实现范围

- 增加「邮箱资产」视角，按显式收件地址和来源聚合连接，显示平台数、登记数、异常连接及影响范围，完整关系列表支持分页。从平台、Outlook、域名邮箱和外部邮箱可打开同一详情抽屉，继续登记、编辑或取码。
- 平台登记新增工作区、账号标识、多登录方式、显式收件别名、解除连接状态、验证规则和生命周期日期。平台密码、2FA 与邮箱连接凭据分别保存。未知日期留空；不自动合并 `+tag`、点号或不同来源的地址。
- 平台取码需要发件人或关键词规则；缺少规则时返回 `VERIFICATION_RULE_REQUIRED` 并提供配置入口。明确选择「查整个邮箱」后才进行邮箱范围查询，其结果不写入平台历史。CF 来信也不再把一个码广播到所有共享登记。
- 导入身份包含来源、工作区、账号标识和规范化登录方式。默认合并保留未提供的凭据，显式替换才恢复默认值；预览显示动作、字段名与目标 ID，不输出秘密值。TXT/CSV 保留前 11 列并追加 10 列元数据。
- 邮箱绑定、代表选择、停用和保留清理在协调器事务中检查全部有效地址引用；普通编辑保留有效的手动代表。`detached` 停止此平台注册取码，保留记录、凭据和邮件保护。
- 实际消费登记前重新核对受限密钥权限；详情、取码、自动化二次读取、编辑、删除、置顶与批量整理均覆盖地址变化的交错。写入与历史码更新再检查记录快照，冲突拒绝提交。
- 新增 D1 增量迁移 `0014_shared_registrations.sql`，便携备份升级到 schema 13。schema 10/11/12 按冻结的原始字段与哈希验证，通过后确定性补默认值；不改旧上传内容或原凭据。
- 四个邮箱身份查询 API、现有登记/导入/取码接口、OpenAPI、Postman、AI 指南和 TypeScript/Python SDK 的 `match` 参数已对齐。SDK 文档增加邮箱资产查询示例，README 接口总数按共享契约核对为 142。受限密钥不能枚举邮箱资产与共享平台注册。

用户操作说明见 [平台账号](PLATFORM-ACCOUNTS.md)、[账号交换](ACCOUNT-TRANSFER.md)、[备份恢复](BACKUP-RECOVERY.md) 和 [API](API.md)。需求来源是 [调研基线](MULTI-PLATFORM-IDENTITY-REQUIREMENTS.md)，它保留实现前的判断；其中的后续建议不自动计入本轮交付。

### 覆盖率与真实外部边界

Node/V8 覆盖率报告中，本轮核心代码行覆盖率：邮箱身份路由 **97.89%**、导入 **98.55%**、平台路由 **93.71%**、取码 **92.61%**、自动化 **95.59%**、存储事务 **98.29%**、备份 **95.23%**。报告的整体 95.90% 包含测试文件，不能当作全站生产代码的覆盖率；浏览器 React 组件不计入这次 Node 报告。

真实数据库验证包含旧行缺元数据时的查询默认值、别名保护、合并保留凭据，以及 D1 → MySQL → MongoDB → Redis A → Redis B → D1 的字段和内容比对。原始数据分页摘要保持旧字段原样，查询层补默认值；同步仍是本应用数据模型的迁移，不是任意数据库的 CDC。

浏览器验证新增共享邮箱与别名两条完整流程，连同现有授权修复、密码回显、导入导出、批量整理、错误恢复和设置流程回归。新邮箱抽屉实际检查桌面、375px 深色布局、嵌套弹窗与焦点返回；对该抽屉的 axe WCAG A/AA 扫描通过。实际查看手机邮箱资产截图。没有提交截图比较基线，也未做全站屏幕阅读器验收，不能据此声称整站视觉回归或无障碍完全通过。

Microsoft/Mail.tm/Mail.gw 的成功、失败和授权回调使用受控响应；本轮没有用用户真实凭据发送或删除邮件，也没有在生产改数据。连接健康仍反映最近记录的检查，不能证明第三方平台账号能成功登录。发件人/关键词匹配是用户规则，不是强隔离或邮件真实性认证；同平台多个并发注册任务的独占领取不在本轮实现范围。

## 上线与剩余范围

本地验收后已推送并发布生产：先保存生产 D1 与认证业务基线、演练迁移，再应用 0014 并发布；原 ID、凭据、人工状态、平台目录和收件关系回读通过。生产当前为 `d1 / legacy`，另有 Redis 直连，没有运行中的 HTTP Connector。详细版本和核对数据见 [生产发布记录](PRODUCTION-RELEASE-2026-11-17-SHARED-REGISTRATIONS.md)。外部便携数据集通过查询默认值兼容新字段；使用自托管 Connector 的部署应同时更新，以使跨库查询和迁移使用一致模型。

邮箱资产汇总目前读取工作区投影后聚合，未做生产规模的负载基准。来信建议“可能注册了某个平台”、自动注册第三方账号、多恢复邮箱和同平台任务领取属于后续产品扩展，没有作为已完成功能宣传。
