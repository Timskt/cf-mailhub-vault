## 明确边界

- 最终校验期间暂停写入，不能宣称任意规模零停机切换。
- 同步只涵盖 MailHub 的数据模型及经应用产生的变更，不是任意数据库的通用迁移或原生 CDC 工具。
- MySQL JSON 查询、MongoDB 集合查询与 Redis 扫描尚未做生产规模负载基准；Redis 单表扫描有十万条（含删除标记）限制。
- 主库彻底丢失且没有完整副本时，系统无法恢复未同步的写入；不会默默切到过期数据。
- 当前没有自动跨 Cloudflare 账号搬迁协调器、控制面备份恢复、密钥重新加密或历史数据集回收功能。
- `sky` 没有发现硬编码根因，已针对浏览器自动填充与输入状态隔离修复并验证；原用户的浏览器扩展环境仍需使用时确认。
- 生产多域名仍需逐个配置 Email Routing/Catch-all；真实 Outlook 需配置自有微软应用或有效 Refresh Token。
