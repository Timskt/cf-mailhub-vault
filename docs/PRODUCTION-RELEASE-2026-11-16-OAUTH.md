## 本次功能

Outlook 工作区增加待处理账号卡片和统一修复面板。从账号列表、平台台账、收件错误、Outlook 验证码错误、凭据编辑或设置进入后，显示目标邮箱和相应诊断。区分授权撤销、应用配置、Graph 权限不足、停用和暂时连接故障；当前续期错误优先，续期异常不计入健康汇总。

授权工具支持自有 Web 应用自动回调，以及公共客户端手动授权。手动方式可粘贴完整回调网址或原始 code，提取、显示/隐藏、复制、兑换并保存 Refresh Token。保存后可查看/复制四段配置、测试连接及读取邮件。发信权限单独勾选，授权操作不会发送邮件。

本次流程绑定管理员会话、PKCE、一次性 state、客户端类型和目标邮箱；Graph 返回身份不匹配时拒绝保存。更新凭据保留原账号 ID、密码、备注、分组、标签、平台关联及停用状态，收件状态设为待检查。持久化的唯一认领标记防止独立 D1 实例重复兑换同一 code；兑换前复查到期时间，保存时拒绝并发覆盖。新管理员登录使用独立随机会话标识，升级前有效 Cookie 仍兼容。

界面沿用 shadcn/ui 弹窗结构，固定标题和操作区，正文独立滚动。检查长回调网址、授权码显示、配置导出及嵌套阅读器在手机、横屏、桌面和深色主题下的布局。兑换失败的提示固定在操作区上方，诊断刷新不会把它挤出视野。平台验证码查收刷新台账状态时，不会反复触发查收请求。
